# Example: drafting-table (one style among many)

An 8-second demo of the `drafting-table` design system, built on the starter:
- pencil-hatched type
- grid and paper grain
- a line → circle → hexagon morph
- a circle flood from paper to blueprint
- a scan line from blueprint to hologram
- corner labels

To run it, copy `src/spec.ts` and `src/Film.tsx` over the starter's files, delete `src/scenes/Scene01.tsx`, then run `npx remotion studio`.

`frame-0.png`, `frame-290.png` and `frame-365.png` are stills rendered from it.
It shows what the helpers can do. It is not a default look.
